# Рецепты · Мангал и казан

Калькулятор и рецепты для мангала и казана: шашлык, люля, курица, плов (расчёт от риса), шурпа, хашлама, рыба, овощи, соусы.
Ввёл вес основы или число людей — получил ингредиенты, шампуры, уголь и литраж казана.
