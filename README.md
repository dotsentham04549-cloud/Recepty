# Книга рецептов

Личная книга рецептов с калькулятором: мангал, казан, овощи, соусы. Рецепты лежат в `recipes.js`.
Ввёл вес основы или число людей — получил ингредиенты, шампуры, уголь и литраж казана.

Открыть: https://dotsentham04549-cloud.github.io/recepty/
На Android: открыть в Chrome → меню → «Установить приложение».
